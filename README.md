# ATLAS CNPJ.EXPLORE

Aplicativo de consulta empresarial de CNPJ com dashboard responsivo, explorador de dados e geração de relatório para impressão/PDF.

**Estado do repositório:** inicializado. O código-fonte da versão preparada para Vercel ainda precisa ser adicionado para habilitar o deploy.

## Publicação

A estrutura da versão preparada para Vercel contém os arquivos `index.html`, `app.js`, `styles.css`, `favicon.svg`, `logo-atlas.png`, `package.json`, `vercel.json` e a pasta `api/`. Importe o repositório na Vercel somente depois que esses arquivos estiverem presentes.

A API utilizada pelo backend é `https://publica.cnpj.ws/cnpj/{cnpj}`; respeite o limite da API pública.
